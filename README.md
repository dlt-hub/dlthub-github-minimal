# dlthub-github-minimal

A template to set up dltHub with GitHub: it creates a repository with a dltHub project, a workspace and CI/CD that deploys on every merge to `main`.
Setup is driven by a coding agent.

## Get started

From an empty directory, start your agent (Claude Code, Codex, pi, etc.) and give it this prompt:

```
Follow the setup instructions from: https://github.com/dlt-hub/dlthub-github-minimal/blob/main/setup.md
```
